# DoGood — тэмдгийн файлын багц

Үндсэн тэмдэг: **Арван гурван холбоос** (Хавтан I). Дэлгэрэнгүй үндэслэл, өнгө, үсэг, хэрэглэх дүрмийг [dogood-identity.html](../dogood-identity.html) хуудаснаас үзнэ үү.

Энэ хавтас доторх бүх файлыг [build.js](build.js) үүсгэдэг. Дахин үүсгэх:

```bash
node .design-draft/dogood-brand/build.js .design-draft/dogood-brand
```

## Юуг хаана ашиглах вэ

| Хэрэглээ | Файл |
|---|---|
| Вэб, апп (вектор) | `svg/mark-green.svg`, `svg/mark-white.svg` |
| Хэвлэл, хар бэх | `svg/mark-ink.svg` |
| Нэрний хуудас, бланк | `svg/lockup-horizontal.svg` |
| Нарийн, босоо талбай | `svg/lockup-vertical.svg` |
| Браузерын таб | `favicon.ico` (16/32/48 багтсан) |
| iOS `apple-touch-icon` | `png/app-icon/app-icon-180.png` |
| Android / PWA | `png/app-icon/app-icon-192.png`, `-512.png` |
| Танилцуулга, сошиал | `png/mark-green/mark-green-512.png` эсвэл `-1024.png` |

SVG-үүдийн `viewBox` нь зургийн ирмэг дээр яг тааруулсан — өөрөөр хэлбэл дотор нь илүү зай байхгүй. Чөлөөт зайг (тэмдгийн өргөний 1/6) байрлуулж буй газартаа өөрөө нэмнэ.

## Хоёр техникийн шийдвэр

**1. 20px-ээс доош хэмжээнд хялбаршуулсан тэмдэг ажиллана.**
16px дээр 13 холбоос уншигдахаа больж, саарал толбо болж бүдгэрдэг. Тиймээс тэр хэмжээнд зөвхөн гадаад дүрсийг нь үлдээсэн `svg/mark-reduced-*.svg` хувилбарыг ашигладаг — `favicon.ico` доторх 16px зураг үүгээр хийгдсэн. 32px-ээс дээш бүх зүйл бүтэн 13 холбоостой.

**2. 48px-ээс доош шугам зузаардаг.**
Стандарт шугамын зузаан жижгэрэхээр цагирагууд нийлж, дотор нь нүх алга болдог. Тиймээс 48px ба түүнээс доош бүх PNG нь илүү зузаан хувилбараар (`mark-*-small.svg`) хийгдсэн. Энэ нь нүдэнд ижил зузаан харагдуулах зорилготой, өөр тэмдэг биш.

## ⚠️ Lockup файлууд — үсгийг заавал хөрвүүлнэ

`lockup-horizontal.svg` болон `lockup-vertical.svg` дотор **амьд текст** байгаа. Хэрэв уншиж буй компьютерт **Libre Caslon Display** суулгаагүй бол өөр үсгээр солигдож харагдана.

Эцсийн хэрэглээнд өгөхөөс өмнө:

1. [Libre Caslon Display](https://fonts.google.com/specimen/Libre+Caslon+Display) болон [Libre Franklin](https://fonts.google.com/specimen/Libre+Franklin)-г суулгана.
2. Файлыг Figma / Illustrator / Inkscape дээр нээнэ.
3. Текстийг **outline / curves болгож хөрвүүлнэ** (Figma: `Ctrl+Shift+O`).

Зөвхөн тэмдгийн файлууд (`mark-*.svg`, `app-icon.svg`, бүх PNG) нь цэвэр геометр учир энэ асуудалгүй, шууд ашиглаж болно.

## Багцад юу байхгүй вэ

- **Хэвлэлийн CMYK / Pantone утга.** Дээрх HEX нь RGB. Хэвлэх газартай ажиллахдаа тохирох CMYK-г нь тодруулах шаардлагатай.
- **Тэмдгийн албан ёсны бүртгэл.** Оюуны өмчийн газарт "DoGood" нэр давхцаж байгаа эсэхийг шалгаагүй байгаа.
